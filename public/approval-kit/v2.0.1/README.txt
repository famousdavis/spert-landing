SPERT® Suite Approval Kit v2.0.1 (Release)

START HERE
These documents help a project manager get SPERT® Suite approved for use inside
an organization. They support an approval process; they are not legal, compliance
or security advice.

Project managers: read SPERT-Approval-Kit_Guide first. Its section 1 gives the
smallest set of documents for each kind of request (local-only, cloud storage,
Connect AI), subject to your organization's own intake requirements.

Reviewers: start with SPERT-Approval-Kit_Reviewer-Summary.

TWO KINDS OF DOCUMENT
  Reference documents (no 'Template' in the name) contain no placeholders.
  Forward the PDF as it is.

  Templates ('Template' in the name) are for you to complete. Open the .docx,
  fill in the highlighted placeholders, then save it as PDF to send on. The
  placeholders are Word content controls: in Word, filling in one copy of a
  common value such as [ORGANIZATION] fills every copy in that file. Other
  editors (Google Docs, LibreOffice) show them as ordinary highlighted text to
  replace by hand. The template PDFs are reference copies: they show the
  unfilled template and have no form fields.

  SPERT-Approval-Kit_Example-Completed-Request shows what a finished
  submission can look like. Its organization, people and decisions are invented.

Every document shows the kit version and its content-review date under the
title. The current kit is published at spertsuite.com/approval-kit. Check it
for a newer version before you submit: product facts and legal documents change.

VERIFYING THE FILES
checksums.txt lists the SHA-256 of every file in this folder except itself,
this README included. The SHA-256 of the zip is published at
spertsuite.com/approval-kit. To check the files:
  macOS or Linux:  shasum -a 256 -c checksums.txt
  Windows:         certutil -hashfile <file> SHA256   (compare by eye)
