SPERT® Suite Approval Kit v1.0.0 (Release)
Built 2026-10-26

START HERE
These documents help a project manager get SPERT® Suite approved for use inside
an organization. They support an approval process; they are not legal, compliance
or security advice.

Reviewers: start with SPERT-Approval-Kit_Reviewer-Summary, a two-page
overview that points to the rest.

Project managers: read SPERT-Approval-Kit_Guide first. It explains the
approval process and which document to give each reviewer. Files whose
names contain "Template" are for you to fill in; the others can be
forwarded with only the placeholders completed.

Each document comes in two formats:
  .pdf   for reading and for forwarding to reviewers as-is
  .docx  for editing in Microsoft Word, Google Docs or LibreOffice

Fill in the highlighted [PLACEHOLDERS] in the .docx version, such as
[ORGANIZATION] and [REVIEWING TEAM], then save it as PDF to send it on.

Every document shows the kit version and the date its content was reviewed
under the title. The current kit is published at spertsuite.com/approval-kit.
Check it for a newer version before you submit, because product facts and
legal documents change.
